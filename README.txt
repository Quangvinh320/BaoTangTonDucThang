HUONG DAN CHAY WEBSITE BAO TANG TON DUC THANG

1. Cai XAMPP, bat Apache va MySQL.
2. Copy thu muc BaoTangTonDucThang vao C:\xampp\htdocs\
3. Mo http://localhost/phpmyadmin
4. Import database/baotang.sql
5. Mo config/config.php va dam bao DB_NAME la baotang_tond_duc_thang, DB_USER=root, DB_PASS=''
6. Truy cap http://localhost/BaoTangTonDucThang/

QUAN TRI:
- URL: http://localhost/BaoTangTonDucThang/admin/login.php
- Tai khoan mau: admin
- Mat khau mau: Admin@12345
- Doi mat khau ngay sau khi dang nhap khi dua len Internet. Hash mau trong file SQL can duoc cap nhat neu khong dang nhap duoc.

GITHUB:
- Khong commit thong tin mat khau hosting that.
- Khong dua file dump database chua du lieu rieng tu len repository cong khai.

LƯU Ý NỘI DUNG:
- Dữ liệu sự kiện/hiện vật trong SQL chỉ là dữ liệu mẫu để kiểm tra chức năng.
- Kiểm chứng thông tin lịch sử, địa chỉ, giờ mở cửa và quyền sử dụng hình ảnh từ nguồn chính thức trước khi công bố.
